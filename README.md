# Java I — IFRS

Curso de introdução à programação em **Java**, realizado pelo IFRS, com foco nos fundamentos da linguagem, construção e execução de programas e conceitos básicos de programação.

## Conteúdos estudados

### Fundamentos de programação

* Diferença entre linguagens de alto nível e linguagem de máquina.
* Processo de construção e execução de um programa.
* Funcionamento do compilador.
* Conceito de código-fonte e programa em linguagem de máquina.
* Noções básicas sobre como um programa é interpretado pelo computador.

### Java

* Estrutura básica de um programa Java.
* Declaração e utilização de variáveis.
* Tipos de dados.
* Tipo `int` para armazenamento de números inteiros.
* Uso de valores do tipo `String`, escritos entre aspas.
* Saída de informações no console.

### `print` e `println`

Foi estudada a diferença entre os comandos de saída:

```java
System.out.print("Olá");
```

e

```java
System.out.println("Olá");
```

O `print` mantém o cursor na mesma linha, enquanto o `println` pula para a próxima linha após exibir o conteúdo.

### Comentários

Também foi estudado o uso de comentários para impedir que determinados trechos sejam considerados pelo compilador.

Comentário de uma única linha:

```java
// Este é um comentário
```

Comentário de múltiplas linhas:

```java
/*
   Este é um comentário
   de múltiplas linhas
*/
```

### Compilação e execução

Foi praticado o processo básico de compilação e execução de programas Java utilizando o terminal.

Exemplo:

```bash
javac Programa.java
java Programa
```

O `javac` é responsável por compilar o código-fonte Java, enquanto o comando `java` executa o programa compilado.
